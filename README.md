# InsightAI - AI Powered Data Analyst

##  Project Overview

InsightAI is an AI-powered business analytics platform that allows users to upload datasets, visualize business performance, and interact with an AI Analyst to generate insights.

The system combines:

- Data Analytics
- Data Visualization
- Natural Language Processing
- Business Intelligence
- AI-driven Recommendations

## Dataset Upload

- Upload CSV and Excel files
- Automatic data preprocessing
- Dynamic column detection
